# Changelog

## 0.0.0

- Initial pure Dart image processing API with no runtime dependencies,
  first-party raw/PNG/baseline and lossless JPEG/GIF/TIFF/WebP codec paths,
  VP8L lossless WebP output, encoded header metadata reads, WebP metadata,
  VP8L/VP8/alpha/animation decoding, core pixel operations, compositing,
  output options, optional IO adapter, generated fixtures, fuzz/property tests,
  benchmarks, and documentation.
